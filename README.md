# AI Assistant

**Team**: European Space Agency

**Participants**: Andres Martin-Barrio

▶️ **Explanatory video:**
[![Watch the demo](https://img.youtube.com/vi/aldugFZ8Pzo/maxresdefault.jpg)](https://www.youtube.com/watch?v=aldugFZ8Pzo)



**Description**:
Interact with a virtual assistant using local or online LLMs with contextual awareness and agentic capabilities.

- You can use the Context variable to provide background to your Assistant and obtain better answers.
- You can also create Agentic capabilities to allow your AI assistant to make actions for you such as Restart, Exit, Save, Add or Remove Components.
- You can also ask the Assistant to give you information about the latest object you selected with your Laser Beam.
- You need to update the Public variables of this Component to set up your model. For example, you can install Ollama in your PC, download your desired model and set the variables accordingly.

**Dependencies**:
No dependent libraries.
